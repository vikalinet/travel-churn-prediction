## 🚀 Запуск интерфейса

### Способ 1: Локально (разработка)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск API сервера
uvicorn src.api.main:app --reload

# Открыть в браузере
http://localhost:8000/
```

### Способ 2: Через Docker

```bash
# Сборка и запуск
docker-compose up --build

# Открыть в браузере
http://localhost:8000/
```

## 🎯 Интерпретация результатов

## 🎯 Интерпретация результатов

### 📈 Метрики модели

При каждом предсказании отображаются метрики качества модели:

| Метрика | Значение | Описание |
|---------|----------|----------|
| **Accuracy** | 91.1% | Точность — доля правильных предсказаний среди всех |
| **Precision** | 86.8% | Точность положительного класса — доля истинно положительных среди предсказанных как положительные |
| **Recall** | 73.3% | Полнота — доля истинно положительных среди всех фактических положительных |
| **F1-Score** | 79.5% | Гармоническое среднее Precision и Recall |
| **ROC AUC** | 97.5% | Площадь под ROC-кривой — качество бинарной классификации |

### 🔍 Что означают Precision и Recall?

#### Precision (Точность) = 86.8%

**Вопрос:** Из всех клиентов, которых модель предсказала как "уйдёт", сколько действительно ушли?

**Ответ:** 86.8% — из 100 клиентов, которых модель классифицировала как "уйдёт", 87 действительно ушли.

**Интерпретация:** Высокий Precision означает, что если модель говорит "клиент уйдёт", то с большой вероятностью это правда.

---

#### Recall (Полнота) = 73.3%

**Вопрос:** Из всех клиентов, которые действительно ушли, сколько модель смогла предсказать?

**Ответ:** 73.3% — из 100 клиентов, которые реально ушли, модель предсказала 73.

**Интерпретация:** Хороший Recall означает, что модель находит большинство клиентов, которые уйдут.

---

#### Trade-off (компромисс) между Precision и Recall

- **Высокий Precision, низкий Recall** — модель осторожная, редко ошибается, но пропускает многих "ушедших"
- **Низкий Precision, высокий Recall** — модель агрессивная, находит почти всех "ушедших", но много ложных тревог

**Наша модель:** Баланс между Precision (86.8%) и Recall (73.3%) — хороший компромисс для бизнеса.

### 🟢 Низкий риск (Low)

**Вероятность:** < 30%

**Значение:** Клиент с высокой вероятностью останется с вами.

**Рекомендации:**
- ✅ Предложите программу лояльности
- ✅ Укрепляйте отношения через регулярные коммуникации
- ✅ Предлагайте дополнительные услуги

### 🟡 Средний риск (Medium)

**Вероятность:** 30% - 70%

**Значение:** Клиент может уйти, но есть шанс его удержать.

**Рекомендации:**
- ⚠️ Персональное предложение со скидкой 10-15%
- ⚠️ Звонок от менеджера для выяснения потребностей
- ⚠️ Предложите эксклюзивные акции

### 🔴 Высокий риск (High)

**Вероятность:** > 70%

**Значение:** Высокий риск потери клиента! Требуется срочное вмешательство.

**Рекомендации:**
- 🚨 Немедленно предложите специальную акцию со скидкой 20-30%
- 🚨 Назначьте персонального менеджера
- 🚨 Предложите эксклюзивные условия и бонусы

## 🐛 Решение проблем

### Проблема: "Модель не загружена"

**Решение:**
1. Проверьте наличие модели в папке `models/`
2. Перезапустите сервер:
   ```bash
   # Остановка
   Ctrl+C

   # Запуск
   uvicorn src.api.main:app --reload
   ```

### Проблема: Ошибка при предсказании

**Решение:**
1. Проверьте заполнение всех полей формы
2. Убедитесь, что возраст в диапазоне 18-100
3. Проверьте значение `services_opted` (должно быть от 1 до 6)

### Проблема: Медленная загрузка

**Решение:**
1. Проверьте загрузку CPU и памяти
2. Перезапустите сервер
3. Убедитесь, что модель загружена в память при старте
