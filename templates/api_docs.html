📋 Обзор API

Это REST API для прогнозирования оттока клиентов туристического агентства. Используйте эндпоинты ниже для получения предсказаний о вероятности оттока клиента.

Base URL: http://localhost:8000

🔗 Эндпоинты

GET /

Главная страница с веб-интерфейсом для прогнозирования оттока.

GET /health

Проверка здоровья сервиса и статуса загрузки модели.

Пример ответа:
{ "status": "healthy", "model_loaded": true }
POST /predict

Получить прогноз оттока для одного клиента.

age integer Required
Возраст клиента (18-100)
frequent_flyer string Required
Часто ли летает: "Yes" или "No"
annual_income_class string Required
Класс дохода: "Low Income", "Middle Income", "High Income"
services_opted integer Required
Количество использованных услуг (1-6)
account_synced_to_social_media string Required
Синхронизация с соцсетями: "Yes" или "No"
booked_hotel_or_not string Required
Бронировал отель: "Yes" или "No"
Пример запроса (curl):
curl -X POST http://localhost:8000/predict ^ -H "Content-Type: application/json" ^ -d '{ "age": 35, "frequent_flyer": "No", "annual_income_class": "Middle Income", "services_opted": 3, "account_synced_to_social_media": "Yes", "booked_hotel_or_not": "No" }'
Пример ответа:
{ "prediction": 0, "probability": 0.25, "risk_level": "Low", "customer_data": {...} }
POST /predict_batch

Пакетное предсказание оттока для нескольких клиентов.

Пример запроса:
curl -X POST http://localhost:8000/predict_batch ^ -H "Content-Type: application/json" ^ -d '{ "customers": [ { "age": 35, "frequent_flyer": "No", "annual_income_class": "Middle Income", "services_opted": 3, "account_synced_to_social_media": "Yes", "booked_hotel_or_not": "No" }, { "age": 42, "frequent_flyer": "Yes", "annual_income_class": "High Income", "services_opted": 5, "account_synced_to_social_media": "No", "booked_hotel_or_not": "Yes" } ] }'
Пример ответа:
{ "predictions": [ {...}, {...} ] }
GET /models

Получить информацию о загруженной модели.

Пример ответа:
{ "model_loaded": true, "model_type": "GradientBoostingClassifier" }

🎯 Уровни риска

Уровень Вероятность Действие
🟢 Низкий (Low) < 30% Программа лояльности
🟡 Средний (Medium) 30% - 70% Персональное предложение (10-15%)
🔴 Высокий (High) > 70% Срочное вмешательство (20-30%)
