ℹ️ Как интерпретировать результаты

  • KS-тест (Kolmogorov-Smirnov) — для числовых признаков. Сравнивает распределение reference vs current.
  • p-value < 0.05 — распределения значимо различаются → дрейф обнаружен.
  • JS-divergence — для категориальных признаков. Значение > 0.2 считается значимым.
  • При обнаружении дрейфа рекомендуется: проанализировать источник данных, проверить ETL, переобучить модель.
